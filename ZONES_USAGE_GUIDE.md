# Руководство по использованию системы зонирования

## Для администратора

### Создание зоны

1. Войдите в систему как администратор
2. Перейдите в раздел **"Зоны"** через навигационное меню (🗺️)
3. Нажмите кнопку **"+ Добавить зону"**
4. Заполните форму:
   - **Название зоны** (обязательно): например, "Центр Сочи"
   - **Описание**: краткое описание зоны
   - **Цвет на карте**: выберите цвет для визуального отличия зоны
   - **Активна**: включите, если зона должна быть доступна для заказов
5. **Нарисуйте границы зоны на карте:**
   - Кликайте на карте, чтобы добавить точки полигона
   - Двойной клик завершит рисование
   - Минимум 3 точки для создания полигона
6. Нажмите **"Создать"**

### Редактирование зоны

1. В списке зон выберите нужную зону (кликните на неё)
2. Нажмите кнопку **"✏️"** (редактировать)
3. Измените данные в форме или перетащите точки полигона на карте
4. Нажмите **"Сохранить"**

### Удаление зоны

1. Найдите зону в списке
2. Нажмите кнопку **"🗑️"** (удалить)
3. Подтвердите удаление

**Внимание:** Удаление зоны может повлиять на существующие цены в прайс-листе.

### Настройка цен для зон

1. Перейдите в раздел **"Прайс-лист"**
2. Нажмите **"+ Добавить цену"**
3. Выберите:
   - Зону отправления
   - Зону назначения
   - Класс автомобиля
   - Цену для клиента
   - Цену для водителя (опционально)
4. Нажмите **"Создать"**

## Для клиентов

### Создание заказа с автоопределением зоны

1. Перейдите в раздел **"Создать заказ"**
2. Заполните информацию о пассажире
3. **Введите адрес отправления:**
   - Введите полный адрес, например: "Сочи, Международный аэропорт"
   - После ввода адреса система автоматически определит зону
   - Если зона определена, вы увидите сообщение: "✓ Зона определена: [название зоны]"
4. **Введите адрес назначения:**
   - Аналогично адресу отправления
5. Если зона не определилась автоматически:
   - Выберите зону вручную из выпадающего списка
6. Выберите класс автомобиля и время подачи
7. Система автоматически рассчитает стоимость
8. Нажмите **"Создать заказ"**

## Технические особенности

### Как работает автоопределение зоны

1. Клиент вводит адрес в текстовое поле
2. При потере фокуса (клик вне поля) система отправляет запрос на сервер
3. Сервер использует Яндекс.Геокодер для получения координат адреса
4. Координаты проверяются на вхождение в полигоны всех активных зон
5. Если адрес попадает в зону - она автоматически выбирается
6. Если адрес не попадает ни в одну зону - клиент выбирает вручную

### Рекомендации по рисованию зон

- **Не делайте зоны слишком маленькими** - это может привести к тому, что адреса не будут попадать в зоны
- **Избегайте пересечений зон** - если адрес попадает в несколько зон, будет выбрана первая найденная
- **Используйте разные цвета** - это упростит визуальное различение зон на карте
- **Покрывайте всю территорию обслуживания** - чтобы клиентам не приходилось выбирать зоны вручную

### Совместимость со старыми данными

Существующие зоны без геометрии (созданные до внедрения карт) продолжат работать:
- Они будут доступны для ручного выбора
- Автоопределение для них работать не будет
- Рекомендуется добавить для них границы на карте

## Устранение неполадок

### Зона не определяется автоматически

**Возможные причины:**
- Адрес введен неточно или неполно
- Адрес находится вне границ всех зон
- Проблемы с Яндекс.Геокодер API

**Решение:**
- Уточните адрес, добавьте "Сочи" в начало
- Проверьте, что зона нарисована на карте и активна
- Выберите зону вручную из списка

### Карта не отображается

**Возможные причины:**
- Не настроен API ключ Яндекс.Карт
- Проблемы с интернет-соединением

**Решение:**
- Обратитесь к администратору системы
- Проверьте подключение к интернету
- См. файл `YANDEX_MAPS_SETUP.md` для настройки

### Цена не рассчитывается

**Возможные причины:**
- Не настроена цена для выбранной пары зон и класса автомобиля

**Решение:**
- Администратор должен добавить цену в прайс-лист для данного маршрута
