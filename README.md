# Taxi PWA - Сервис такси для Сочи

MVP PWA-приложение для управления заказами такси с тремя типами пользователей.

## Описание

Сервис позволяет:
- **Заказчикам** создавать заказы на трансфер с автоматическим расчетом цены
- **Водителям** просматривать и брать доступные заказы
- **Администраторам** управлять водителями, автомобилями и прайс-листом

## Технологический стек

### Backend
- Django 5.0
- Django REST Framework
- PostgreSQL
- JWT аутентификация
- Push-уведомления

### Frontend
- React
- React Router
- Axios
- PWA (Progressive Web App)

## Структура проекта

```
taxi-pwa/
├── backend/        # Django REST API
└── frontend/       # React PWA приложение
```

## Быстрый старт

### Backend

1. Перейдите в директорию backend:
```bash
cd backend
```

2. Создайте виртуальное окружение и установите зависимости:
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

3. Настройте .env файл:
```bash
cp .env.example .env
# Отредактируйте .env с вашими настройками PostgreSQL
```

4. Создайте базу данных и примените миграции:
```bash
createdb taxi_pwa_db
python manage.py makemigrations
python manage.py migrate
```

5. Создайте суперпользователя:
```bash
python manage.py createsuperuser
```

6. Запустите сервер:
```bash
python manage.py runserver
```

Backend будет доступен по адресу: http://localhost:8000

### Frontend

1. Перейдите в директорию frontend:
```bash
cd frontend
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите development сервер:
```bash
npm start
```

Frontend будет доступен по адресу: http://localhost:3000

## Функциональность

### Кабинет заказчика
- Создание заказа на трансфер
- Выбор маршрута (зон)
- Выбор класса автомобиля
- Автоматический расчет стоимости
- История заказов

### Кабинет водителя
- Лента доступных заказов
- Взятие заказа
- Управление статусами заказа (взял/еду/выполнено)
- Управление своими автомобилями
- Редактирование профиля

### Кабинет администратора
- Управление водителями (CRUD)
- Управление автомобилями (CRUD)
- Просмотр всех заказов
- Управление прайс-листом
- Управление зонами и классами авто

## Дополнительная информация

- Минимальное время до подачи: +1 час от текущего времени
- Фиксированные цены между зонами
- Поддержка классов авто: Стандарт, Комфорт, Минивэн, и др.
- Работа только в зоне Сочи
