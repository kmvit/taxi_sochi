# Настройка Яндекс.Карт API

## Получение API ключа

1. Перейдите на сайт [Яндекс.Карты для разработчиков](https://developer.tech.yandex.ru/)
2. Войдите в свой аккаунт Яндекс или зарегистрируйтесь
3. Перейдите в раздел **"JavaScript API и HTTP Геокодер"** (НЕ Static API!)
4. Нажмите "Получить ключ"
5. Заполните форму:
   - Название проекта: "Taxi Sochi"
   - Описание: "Сервис такси с зонированием"
   - **Обязательно выберите "JavaScript API" и "HTTP Геокодер"** (Static API не подходит!)
6. Скопируйте полученный API ключ

## Настройка backend

1. Откройте файл `.env` в директории `backend/` (создайте, если не существует)
2. Добавьте строку:
```
YANDEX_MAPS_API_KEY=ваш_api_ключ_здесь
```

## Настройка frontend

1. Откройте файл `frontend/public/index.html`
2. Найдите строку:
```html
<script src="https://api-maps.yandex.ru/2.1/?apikey=&lang=ru_RU" type="text/javascript"></script>
```
3. Замените `apikey=` на `apikey=ваш_api_ключ_здесь`

**Важно:** Для production рекомендуется настроить ограничения по доменам в настройках API ключа.

## Лимиты бесплатного использования

- JavaScript API: 25,000 запросов/день
- HTTP Геокодер: 25,000 запросов/день

Этого достаточно для большинства малых и средних проектов.

## Проверка работы

1. Запустите backend: `cd backend && venv/bin/python manage.py runserver`
2. Запустите frontend: `cd frontend && npm start`
3. Войдите как админ
4. Перейдите в раздел "Зоны"
5. Попробуйте создать новую зону, нарисовав полигон на карте

## Возможные проблемы

### Карта не загружается
- Проверьте, что API ключ правильно указан в `index.html`
- Откройте консоль браузера (F12) и проверьте наличие ошибок
- Убедитесь, что JavaScript API включен для вашего ключа

### Геокодирование не работает
- Проверьте, что API ключ указан в `.env` файле backend
- Убедитесь, что HTTP Геокодер включен для вашего ключа
- Проверьте логи backend на наличие ошибок

### Ошибка "Operation not permitted" при установке зависимостей
- Используйте команду: `venv/bin/pip install -r requirements.txt`
- Или активируйте venv: `source venv/bin/activate` (Linux/Mac) или `venv\Scripts\activate` (Windows)
