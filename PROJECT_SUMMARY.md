# Taxi PWA - Сводка проекта

## Описание

MVP PWA-приложение для управления заказами такси в Сочи с тремя типами пользователей.

## Реализованные функции

### ✅ Backend (Django + PostgreSQL)

1. **Модели данных:**
   - User - пользователи с ролями (admin, driver, customer)
   - Driver - профили водителей
   - Car - автомобили с привязкой к водителям
   - CarClass - классы автомобилей (Стандарт, Комфорт, Минивэн, и т.д.)
   - Zone - зоны в Сочи (Центр, Аэропорт, Адлер, Красная Поляна)
   - Pricing - прайс-лист между зонами
   - Order - заказы на трансферы

2. **API Endpoints (Django REST Framework):**
   - JWT аутентификация (login, refresh, register)
   - Управление профилем пользователя
   - CRUD для водителей (для админа)
   - CRUD для автомобилей (для админа и водителей)
   - Список зон и классов авто
   - Расчет цены по маршруту
   - Создание заказов (для заказчиков)
   - Список доступных заказов (для водителей)
   - Взятие заказов и управление статусами
   - История заказов

3. **Функции:**
   - Валидация времени подачи (минимум +1 час)
   - Автоматический расчет цены из прайс-листа
   - Фильтрация заказов по роли пользователя
   - Django Admin для полного управления
   - Management команда для создания тестовых данных

### ✅ Frontend (React + PWA)

1. **Аутентификация:**
   - Страницы входа и регистрации
   - JWT токены с автоматическим обновлением
   - Защищенные маршруты по ролям
   - Контекст аутентификации

2. **Кабинет заказчика:**
   - Создание заказа с выбором:
     - Зон отправления и прибытия
     - Класса автомобиля
     - Даты и времени подачи
     - Количества пассажиров
   - Автоматический расчет и отображение цены
   - История всех заказов
   - Просмотр статусов заказов

3. **Кабинет водителя:**
   - Лента доступных заказов (фильтр по классу авто)
   - Взятие заказа одной кнопкой
   - Управление статусами своих заказов:
     - Взял → Еду к клиенту → Выполнено
   - Просмотр списка своих автомобилей
   - Автообновление списка заказов каждые 30 секунд

4. **Кабинет администратора:**
   - Dashboard с общей статистикой
   - Просмотр всех заказов с фильтрацией
   - Список всех водителей
   - Список всех автомобилей
   - Просмотр прайс-листа
   - Ссылки на Django Admin для полного управления

5. **PWA функционал:**
   - Manifest.json для установки приложения
   - Service Worker для кеширования
   - Возможность установки на домашний экран
   - Работает как нативное приложение

### ✅ Дополнительно

1. **Email интеграция (заглушка):**
   - Структура EmailParser для парсинга писем от партнеров
   - API endpoint для создания заказа из email
   - Готовность к интеграции с реальным email

2. **Тестовые данные:**
   - 4 водителя с автомобилями разных классов
   - 7 зон в Сочи
   - 7 классов автомобилей
   - Примеры цен в прайс-листе
   - Тестовые учетные записи для всех ролей

3. **UI/UX:**
   - Современный дизайн с градиентами
   - Адаптивная верстка для мобильных устройств
   - Цветовая кодировка статусов заказов
   - Удобная навигация
   - Информативные сообщения об ошибках

## Технологии

### Backend
- Django 5.0
- Django REST Framework
- JWT аутентификация (djangorestframework-simplejwt)
- PostgreSQL
- CORS headers
- Push notifications (готово к интеграции)

### Frontend
- React 18
- React Router 6
- Axios
- date-fns
- Workbox (Service Worker)
- PWA
