# Changelog: Система зонирования с картами

## Дата: 2026-01-19

### Добавлено

#### Backend

1. **Модель Zone (расширена)**
   - `geometry` - JSONField для хранения полигона в формате GeoJSON
   - `center_lat` - широта центра зоны
   - `center_lon` - долгота центра зоны
   - `color` - цвет зоны на карте (HEX формат)

2. **API Endpoints**
   - `POST /zones/detect-by-address/` - определение зоны по адресу
   - `POST /zones/detect-by-coordinates/` - определение зоны по координатам
   - Обновлен `GET /zones/` - админы видят все зоны, остальные только активные

3. **Зависимости**
   - `shapely==2.0.2` - для работы с геометрией и проверки точки в полигоне
   - `requests==2.31.0` - для запросов к Яндекс.Геокодер API

4. **Настройки**
   - `YANDEX_MAPS_API_KEY` - API ключ для Яндекс.Карт

5. **Миграция**
   - `0002_zone_center_lat_zone_center_lon_zone_color_and_more.py`

#### Frontend

1. **Компоненты**
   - `ZoneMap.js` - интерактивная карта для работы с зонами
     - Отображение всех зон с цветовой кодировкой
     - Рисование новых полигонов
     - Редактирование существующих полигонов
     - Интеграция с Яндекс.Карты API 2.1

2. **Страницы**
   - `ManageZones.js` - управление зонами для админа
     - Список зон с фильтрацией
     - Создание/редактирование/удаление зон
     - Визуальный редактор границ на карте
     - Выбор цвета для каждой зоны

3. **Обновленные страницы**
   - `CreateOrder.js` - автоопределение зон по адресу
     - Поля ввода полного адреса
     - Автоматическое определение зоны при вводе адреса
     - Визуальная индикация определенной зоны
     - Возможность ручной корректировки
   
   - `ManagePricing.js` - добавлена кнопка перехода к управлению зонами
   
   - `Layout.js` - добавлен пункт меню "Зоны" для админа
   
   - `Dashboard.js` (admin) - добавлен маршрут `/admin/zones`

4. **Интеграция**
   - Подключен Яндекс.Карты API 2.1 в `index.html`

### Изменено

1. **Логика создания заказа**
   - Приоритет: автоопределение зоны → ручной выбор
   - Адрес теперь обязательное поле (не только детали)
   - Улучшена валидация адресов

2. **Навигация админа**
   - Добавлен раздел "Зоны" между "Автомобили" и "Прайс-лист"

### Технические детали

#### Формат хранения геометрии

```json
{
  "type": "Polygon",
  "coordinates": [
    [
      [39.7231, 43.5855],
      [39.7331, 43.5855],
      [39.7331, 43.5955],
      [39.7231, 43.5955],
      [39.7231, 43.5855]
    ]
  ]
}
```

#### API запросы

**Определение зоны по адресу:**
```bash
POST /zones/detect-by-address/
Content-Type: application/json

{
  "address": "Сочи, Международный аэропорт"
}
```

**Ответ:**
```json
{
  "zone": {
    "id": 1,
    "name": "Аэропорт",
    "description": "Международный аэропорт Сочи",
    "color": "#3b82f6",
    "geometry": {...},
    "is_active": true
  },
  "coordinates": {
    "lat": 43.4499,
    "lon": 39.9566
  }
}
```

### Обратная совместимость

- Существующие зоны без геометрии продолжают работать
- Ручной выбор зон остался доступен
- Старые заказы не требуют обновления
- Миграция не требует действий от пользователя

### Требования

#### Backend
- Python 3.11+
- Django 5.0.1
- PostgreSQL (или другая БД с поддержкой JSONField)

#### Frontend
- React 18.2+
- Современный браузер с поддержкой ES6+

#### API ключи
- Яндекс.Карты API ключ (бесплатно до 25,000 запросов/день)

### Инструкции по развертыванию

1. Установите зависимости backend:
```bash
cd backend
venv/bin/pip install -r requirements.txt
```

2. Примените миграции:
```bash
venv/bin/python manage.py migrate
```

3. Настройте API ключ (см. `YANDEX_MAPS_SETUP.md`)

4. Перезапустите сервер

5. Войдите как админ и настройте границы существующих зон

### Известные ограничения

1. Яндекс.Карты API требует интернет-соединения
2. Лимит 25,000 запросов/день на бесплатном тарифе
3. Геокодирование работает только для адресов в России
4. При пересечении зон выбирается первая найденная
